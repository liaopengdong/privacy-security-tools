Start with the outcome

Choose the tool based on the decision, conversion, format, or check you need to complete. The best result comes from clear inputs and a quick review of edge cases.

Recommended tools

  • Password Generator: Generate random passwords with length and character options.
  • Passphrase Generator: Generate memorable passphrases from a local word list.
  • SHA-256 Hash Generator: Generate SHA-256 hash from text locally.
  • File Hash Checker: Generate SHA-256 hash for an uploaded file in the browser.
  • Random Number Generator: Generate cryptographically strong random numbers in a range.

Review the result

Browser-based tools are fast, but input quality still matters. Check assumptions, units, formats, and context before using results in important work.
